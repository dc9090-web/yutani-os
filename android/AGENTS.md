# Yutani OS for Android

A Kotlin Multiplatform app (Compose Multiplatform) that shows the site's screens from a full copy
of the data kept on the phone. Design: `docs/superpowers/specs/2026-11-22-android-app-design.md`.

## Layout

- `shared/` — everything: models, the on-phone store, sync, theme, components, screens (`commonMain`).
  `androidMain` and `jvmMain` hold only the network engine and file system.
- `androidApp/` — the Android shell: Google sign-in (Credential Manager), the encrypted token,
  the hourly background sync, the launcher icon.
- `desktopApp/` — a development window. Never shipped.
- `../api-fixtures/v1/` — the contract with the site: one JSON file per API route, generated by the
  site (`npm run api:fixtures`) and decoded by this app's tests. `README.md` there describes every type.

## Commands

```
export JAVA_HOME=~/tools/jdk-21 ANDROID_HOME=~/Android/Sdk
./gradlew :shared:jvmTest                      # all tests
./gradlew :shared:jvmTest -Pshots=/some/dir    # also draw every screen to PNG tiles from the fixtures
./gradlew :androidApp:assembleDebug            # debug APK
./gradlew :androidApp:assembleRelease          # signed APK (needs keystore.properties)
./gradlew :desktopApp:run                      # the window (needs a display; set YUTANI_SITE_URL and YUTANI_TOKEN)
```

## Rules

- Run the tests after every change. Both the Android and the desktop target must build before a task is done.
- No Android-only API in `commonMain`.
- Screens never touch the network. They read the phone's copy with `resource(path, serializer)`;
  only a sync writes to it.
- The app computes nothing the site computes. It shows the strings the API sends. The exceptions:
  anything that depends on the current time (recomputed from the raw times beside it, see
  `time/Format.kt` and `model/Training.kt`) and the drone selector's sum.
- Models are hand-written `@Serializable` classes with defaults, checked against the fixtures by a test.
- The site address, the Google client ID and the signing key are never in the repo
  (`local.properties`, `keystore.properties`, both git-ignored).
- Colours, type and spacing come from `ui/Theme.kt` (the `--yo-` tokens) and `ui/Components.kt`.
